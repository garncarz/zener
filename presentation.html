Zener / computational rheology

Stress leaves a memory

A nonlinear viscoelastic model for turning loading history into strain, then finding the parameters that explain the observation.

model.pyPyGADtests + operations

Open with the physical question: after a rock is loaded, which part of the deformation is immediate and which part remembers the past?
01 / physical intuition

Stress is the input. Strain is the response.

Stress is the applied force per area. Strain is the resulting relative deformation.

For a time-varying load, the current strain depends on both the present stress and the path taken to reach it.

The experiment is a sequence of ramps, holds, reversals, and pauses.

σ(t)  →  ε(t)  with memory of  σ(τ), 0 ≤ τ ≤ t
02 / the mathematical model

One response, three mechanisms

Nonlinear elastic

Immediate deformation and stress-dependent curvature.

Viscoelastic branch

A delayed mechanism with stress and strain relaxation times.

Tau_sTau_e

Kelvin chain

Many delayed elements approximate a broad spectrum.

Em_F[i]Tau_e_F[i]
εtotal = εNL + εVE + Σi εKV,i

In the default configuration, 19 Kelvin-Voigt elements make a 42-parameter inverse problem.

03 / model.py

The nonlinear term keeps the sign and bends the curve

εNL(σ) = 1 / EmNL · [ σ + Alpha · sign(σ) · |σ|Beta ]
@njit def fEpsNL(Sig, EmNL, Alpha, Beta): return (1 / EmNL) * ( Sig + Alpha * np.sign(Sig) * np.abs(Sig) ** Beta )

The implementation then walks each loading segment, carries cumulative time forward, and evaluates exponential relaxation terms from earlier segments.

04 / acceleration

Numba turns the hot loop into compiled code

The expensive work is numerical and repetitive: time steps × stress segments × Kelvin elements.

Numba compiles the functions marked with @njit. The Python model stays readable while the inner loop runs close to machine-code speed.

A few annotations, no separate rewrite of the model.

@njit

on fSig, fEps, fEpsNL, fEpsVE, fEpsKV, and _compute_all

same equations  ·  compiled numerical kernel  ·  many more fitness evaluations
